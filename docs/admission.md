# 院校资格、资料质量与前 1,000 所预排名

原来的 16,132 条可用评分记录是未经院校身份筛选的集合，不能直接当作大学榜单。Netflix 等公司出现在榜单的问题在导出前处理，不靠前端名称黑名单。

## 预处理顺序

1. 检查指标与总分有效性；一致的重复记录合并，分数冲突隔离。
2. 使用 `scripts/institution_eligibility.py` 的正向高等教育类型证据，或高教描述与外部大学排名标识的交叉证据进行准入。OpenAlex / ROR 标识、学校名字本身都不足以准入。
3. 明确的企业、非高教学校、消歧义页等排除；历史状态、大学系统与证据不足的实体进入待核验区。待核验不代表不是大学，当前规则有意保守。大学系统与独立校区不混排行，避免重复范围；“属于某大学系统”不等同于系统本身。
4. 检查学校名、简介、有效官网、国家代码及非零研究成果和引用覆盖。Logo、校园图、财务和师资指标不作为准入必要条件。
5. 通过者按来源综合分预排名，保留前 1,000 所，生成静态 JSON。网站名次按收录集合重算；来源分数与来源名次不改写。

Netflix `Q907311`、清华控股 `Q17054681` 被明确排除；伊顿公学 `Q192088` 不具备高教准入证据而隔离；Queen's University 的消歧义实体 `Q422402` 排除，不影响真实大学实体。Sciences Po `Q859363` 的评分冲突仍单独处理。

完整决策、证据、资料缺项、重复与冲突见 `reports/<当前 catalog release>/quality.json`；版本指针在 `src/data/catalog.json`。源 DB / Parquet 保持只读；准入模块在 UniDataPipeline 环境中作为网站导出前的预处理步骤执行。旧公开目录移入 `archives/<旧 release>/`，旧 Netflix JSON 不再通过网站提供，同时保留本地恢复能力。

## 排名解释

2026-09-13 的 `higher-education-v2` 批次：16,133 个源实体中，1 个分数冲突隔离、258 个明确排除、5,319 个身份或范围待核验、10,555 个通过身份规则；其中 9,696 个通过资料质量检查，最终发布 1,000 所。未发布的记录不代表全部不合格大学，可能属于缺资料、范围待确认或低于预排名截取线。

默认“本站名次”按入选集合的来源综合分重排。调权重排的也是已入选 1,000 所，不会召回预筛选之外的学校。先对集合排名，再过滤地区和名称；并列使用保留 12 位小数后的竞争名次（1、1、3）。

20 个旧版 2025 学科榜按需读取，只显示映射到当前入选学校的记录，保留原始学科分数和名次；它们不是新综合榜的重算结果。

六所样本使用静态 `/zh/university/Q…/` 页面，其他入选学校使用 `/zh/university/?id=Q…` 按需读取自己的双语 JSON。被排除或未入选的 ID 不提供详情数据。

## 验证与限制

数据校验覆盖准入证据、前 1,000 名上限、Netflix 回归、网站名次、资料与榜单一致性、文件 SHA256、媒体尺寸与授权字段。自动准入及图片关联仍需人工抽查，不能视为官方认证。较少见、尚未核实的 Wikidata 类型可能导致真实学校被暂时隔离，需审核后扩充准入类型。

开发地址为 `http://192.168.1.220:4322/zh/`。同一服务允许 `http://lambdax220:4322/zh/`；客户端需要能将这个名字解析到 `192.168.1.220`。
