# Local university images

After the September 13 enrichment, bundle `catalog-20260913T072051Z` contains 1,000 selected universities, 705 logos and 836 campus photographs, totaling 126,840,034 image bytes. The 85 newly added photographs all received contact-sheet visual review in addition to source identity, license, attribution, dimensions and hash checks. Another 71 verified logos were merged separately without replacing existing marks. The earlier 751 photographs received sampling rather than exhaustive editorial review. Missing assets remain explicit nulls with visible fallbacks. Attribution is available on each school page and the image credits page.

`node scripts/media-acquire.mjs --hero-limit 1000` builds a separate local media bundle for the current catalog (maximum 1,000 records). `--root /path/to/staging` selects another complete project/export root; `--limit 30 --hero-limit 20` supports a small trial. The six sample universities are additionally prioritized when present. Missing usable images remain explicit `null`, never fabricated campus photographs. After a catalog update, `--reuse-from catalog-...` reuses hash-verified selected assets from that release under `public/media` or `archives/<release>/media`; metadata/source identity must still pass the current selection policy.

The process reads existing image associations in `dev.entity_images` and original/optimized objects from local S3 using the pipeline host's environment. Database transactions are read-only; credentials never leave that host. Wikimedia Commons API requests retrieve current copyright and attribution metadata, through the configured `https_proxy` / `http_proxy` when needed. S3 provides the actual associated bytes. No visitor requests Wikipedia, S3 or any image proxy.

Only explicit CC BY, CC BY-SA, CC0 or public-domain metadata with an author and license reference is accepted, plus the narrowly checked Commons `Copyrighted free use` grant: exact license name, matching template category, explicit `Own work` credit, named author and `AttributionRequired=false`. The [Commons template](https://commons.wikimedia.org/wiki/Template:Copyrighted_free_use) explicitly grants use, redistribution and modification including commercial use; its English template source was checked on 2026-09-13. This does not interpret an unknown license as free. Non-free English Wikipedia logos, unknown licenses and missing author records are excluded. Logos may still be trademark protected; caching is not a claim that trademarks are unrestricted. Photo candidates must be the school's existing Wikidata image, sufficiently large, and not labelled as a portrait, logo, drawing or map. Image identity needs editorial review beyond these source associations. No AI-generated or generic stock campus is substituted.

Published assets are raster WebP: logos fit inside 160×160, photos inside 1440×960, without upscaling. Source SVG is never shipped, and active/external SVG references are rejected before rasterization. Metadata preserves source URL, Commons source page, author, license, description, transformation, local hash, dimensions and size. All attribution fields are plain text. UI must display photo attribution and link to the source and license.

Manifest: `public/media/<catalog-release>/manifest.json`, keyed by Wikidata ID under `universities`, each with nullable `logo` / `hero`. Manifest publication uses an atomic rename after asset files are ready. Assets are content-hashed. Retries reuse verified existing images. Commons metadata and source lookup caches stay in ignored `archives/media-cache` for reproducible, economical preprocessing; remove a cache deliberately when a fresh license review is required. The script reports verified coverage, bytes and acquisition failures; missing assets require a visible UI fallback.

Each school also gets `/media/<catalog-release>/universities/<QID>.json` containing `{release,id,logo,hero}`, so a detail page only fetches its own image metadata. `node scripts/media-validate.mjs` verifies selected school IDs, image hashes, byte counts, raster dimensions, accepted license/attribution and per-school metadata consistency.

`scripts/media-overrides.json` holds the 85 reviewed enrichment selections, including exact source URLs and university identity evidence. Overrides go through the same license checks and preserve reuse across future catalog exports. NUS retains its original S3 photograph and explicitly verified own-work `Copyrighted free use` Commons grant.

`scripts/logo-overrides.json` likewise preserves the 71 logo selections (including current P154/P94 school associations). When Commons heraldry metadata omitted its author, only an explicitly reviewed artist field and derivative credits from a recorded Commons revision may restore it, and only while current license name/URL still match. Historical marks are rejected. Commons PNG thumbnails can avoid parsing a source SVG; active/external SVG constructs remain blocked. Logo source GIFs are rasterized to a static WebP frame, never shipped as animation. The pre-logo-merge bundle is backed up at `archives/logo-staging/before-merge-media`.

## Incremental discovery and review

The September 13 discovery checked current Wikidata P18 claims, free Wikipedia page images, and all paginated article image lists. Wikipedia responses must return the exact university Wikidata QID; four ambiguous/malformed school titles required explicit disambiguation. There were 5,337 candidates across the 249 initially missing schools. Only 194 article photographs across 88 schools passed the additional title/source identity screen; candidate coverage is not publishable-photo coverage.

`scripts/media-discovery-current.mjs`, `media-discovery-disambiguated.mjs` and `media-discovery-reviewed.mjs` reproduce that discovery into ignored `archives/media-discovery/`. `node scripts/media-enrich-heroes.mjs` downloads eligible candidates into independent `archives/hero-staging/`; it never updates a release pointer or public assets. It uses current Commons imageinfo thumbnail URLs (including `thumb.wikimedia.org`) with bounded downloads and preserves full author/license/source metadata. Failed downloads are not automatically retried on reruns; `--retry-failed` is an explicit option to use after the service's retry interval. No private university CDN or stock photograph is substituted.

Before publication, inspect contact sheets and maintain `scripts/media-hero-review.json`. This batch rejected two university marks and one people-dominated close-up; Reading and Alabama received alternative campus photographs. `--review-only` applies the rejection list without network requests. Yale now uses its Old Campus at dusk, UCLA Royce Hall after rain, and Princeton a real gate photograph instead of the legacy watercolor.

`node scripts/media-merge-additions.mjs --bundle archives/hero-staging --kind hero` explicitly merges a reviewed increment into the current release (or `--root` staging), validates every new file before writes, fills only empty slots, and preserves existing logos. The original complete bundle was backed up at `archives/hero-staging/before-merge-media`. Always run `node scripts/media-validate.mjs` after merging. One designated publisher must merge logo and hero batches sequentially to avoid manifest write conflicts.

Future CDN migration only needs to change the local asset URL prefix or upload this bundle; retain the manifest and attribution. The static website does not need a runtime backend for either approach.
