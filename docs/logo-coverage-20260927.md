# 校徽覆盖率检查与补充

本轮检查全部 1,000 所已收录学校，对原缺失的 294 所访问其已有资料中的官网地址。候选先暂存，结合页面标题、学校名称、标识图案逐项检查后再发布；不是看到官网里的任意 logo 图片就自动采纳。

| 范围 | 补充前 | 补充后 |
| --- | ---: | ---: |
| 前 50 名 | 44 / 50（88%） | 50 / 50（100%） |
| 前 100 名 | 81 / 100（81%） | 94 / 100（94%） |
| 前 200 名 | 153 / 200（76.5%） | 178 / 200（89%） |
| 前 500 名 | 374 / 500（74.8%） | 441 / 500（88.2%） |
| 全部学校 | 706 / 1,000（70.6%） | 783 / 1,000（78.3%） |

新增 77 所，剩余 217 所仍未发布校徽。本轮优先下载有候选的前 100 所学校的标识并进行视觉审核，其余候选尚待审核；不是全部剩余学校都没有可用资源。

## 数据与复现

- `reports/<release>/logo-coverage-20260927.json`：覆盖分层、全部剩余学校及状态。
- `archives/logo-coverage-20260927/`：原始官网 HTML、候选来源、原图及视觉检查图。原图缓存按 URL 散列区分，防止候选顺序变化时复用错误图片。
- `scripts/logo-review-20260927.json`：77 条明确审核选择及拒绝原因。
- `scripts/official-logo-additions.json`：学校 ID、准确图片 URL、官网来源、源文件 SHA-256、审核证据。
- `archives/logo-corrections-20260927/`：发布原图缓存及旧记录备份。

```sh
python3 scripts/logo-coverage.py --discover
node scripts/logo-stage-official.mjs
# 查看候选图和官网证据，再修改明确的审核选择；此步骤不自动审批。
node scripts/logo-register-reviewed.mjs
node scripts/logo-correct-official.mjs
python3 scripts/logo-coverage.py
npm run data:validate
npm test
```

媒体清单在服务端模块初始化时读取，LAN dev 发布后需重启开发服务器；静态生产部署需重新构建。图片采用内容散列文件名。

## 本轮发现与限制

- 中国科大标识嵌在 SVG image 元素，不能只找 HTML img；浙江大学标识由 CSS 引用，SVG 的 24px 视口实际包裹 200px PNG。提取的是原始嵌入 PNG，未生成或重绘学校标志。
- 透明白色标识增加深色对比底色；不裁切、不修改标识图案，处理过程保留在元数据中。
- 拒绝校庆纪念图、联盟标志、院系标识、过小图标、留白过多的图片。南澳大学旧官网跳转到阿德莱德大学，拒绝将后继机构的标识填给旧学校。
- 403／401、超时和证书异常记录为采集问题，不绕过访问限制或关闭 TLS 校验。
- 官网来源不等于开放授权。本轮新增素材用于现有 LAN 开发预览中的院校识别，均标注保留所有权利；不宣称学校许可或背书，公开分发前需另行核验使用权限。其余 Commons 图片仍沿用原授权策略。

本轮未修改大学评分、师生数据或院校准入名单。
