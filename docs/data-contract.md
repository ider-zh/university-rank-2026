# 静态数据契约 v1（样本阶段）

机器可执行规范：`schemas/release.schema.json`。`scripts/validate-data.mjs` 在 JSON Schema 校验之外，执行文件哈希、跨文件引用、成绩一致性和雪碧图坐标检查。`npm run build` 必须先通过数据校验。

## 产物与边界

- `src/data/release.json` 仅指向当前已通过验证的版本。
- `public/data/<release>/manifest.json` 定义版本、源快照、数据类型、计分元数据及文件清单。
- `ranking/core.json` 包含六所样本大学的名称、地区、真实校徽引用、完整精度指标、源总分、源名次。
- `universities/<qid>/profile.{zh,en}.json` 分语言简介、官网、百科链接、坐标；无对应内容时回退，并标记实际内容语言。
- `universities/<qid>/alumni.json` 包含固定样本、抽样参数、人物来源、图片出处和图集坐标。
- `public/media/<release>/` 是从 S3 导出的校徽和本次生成的 WebP 雪碧图；文件名包含内容哈希。
- `reports/<release>/quality.json` 是开发用完整审计报告，包含每组重复成绩、Nature Index 源记录、85 校覆盖差异（实际数量以报告为准），不进入网站构建产物。
- `quality-summary.json` 仅公开汇总计数；校园照片与新闻不在本期数据契约内。

## 样本不等于发布榜单

本版本固定 `kind: sample`、`scoring.status: unreviewed`、`completeUniverse: false`，不能声称覆盖完整排名集合。预览页设置 `noindex`。六所大学的排名字段命名为 `sourceRank`、总分为 `sourceScore`，避免将未校验来源称为正式排名。

五维字段统一为 `reputation / academic / financial / faculty / alumnus`。原始精度保留，计分单位为 0–1，UI 显示时乘 100 并格式化。默认权重为 0.25 / 0.50 / 0.10 / 0.05 / 0.10；校验器验证加权结果等于来源总分。名次原样保留，不在六校集合中重排，也不提供会误导为全球排名的自定义调权。

正式榜单的收录集合、并列规则、旧数据的 log1p 映射以及旧学科榜版本尚未定稿。当前契约将这些差异显式隔离；以后切换正式模式需要新的契约和计分验收，不能仅将 sample 标签改成正式。

## 校友抽样

每校先按已有影响力字段取最多 200 条有头像的关联记录，人物 ID 去重，然后按 `SHA256(seed:universityId:personId)` 排序，选择最多 16 张能读取、解码的图片。固定 seed 为 `university-rank-sample-v1`。图片失效时继续选下一人；故障计入报告。相同源数据、可用图片与种子得到相同的名单顺序。底层数据库变化可能使以后导出的结果不同；每个版本保存了实际名单。

头像统一为 120×150，每行四张；16 人图集为 480×600。校友 JSON 保存 x/y/width/height，验证器同时检查真实 WebP 尺寸、坐标边界及名单顺序。展示时在用户展开模块后才请求名单和图集；失败可重试，图片失败仍显示姓名及人物链接。

人物关联来自旧数据库 `educated_at`，目前只有来源追溯，没有逐人证实毕业关系，因此明确记录 `relationshipVerified: false`，预览说明其可能包含其他教育经历。抽样仅影响展示，不改变全量校友统计或排名分数。

## 数据质量处置

完整报告保留重复组的全部原始成绩与 Nature Index 链接记录，不任意选择冲突分数。相同指标但不同名次的重复组标记为需上游去重后重算；指标不同的组标记为需解决来源链接后重算。样本只允许读取恰好一行成绩的学校。

缺失旧学校按“是否在候选快照”“是否在 OpenAlex 链接集合”附加证据，但不自动推断学校应当被排除。源数据保持只读，这些业务决策与上游计分变更留待后续明确处理。

## 更新与可复现

执行 `npm run data:export`。本地脚本经 SSH 将导出程序通过 stdin 送到既有流水线 Python 环境；远端只读 PostgreSQL、Parquet、S3，在内存生成 ZIP，不落盘、不安装依赖、不修改服务。

本地先解压到临时目录，用 Sharp 将校徽统一缩放为最大 256×256 的透明 WebP，更新资源引用和哈希；然后通过 JSON Schema、哈希和语义校验，再写入新的版本目录，最后更新当前版本指针。版本目录不覆盖已有内容，旧版本目录可用于回退（将指针恢复为对应版本）。源成绩、Nature Index 与 OpenAlex 文件的 SHA256 保存于完整报告；图片名也含哈希。

运行预览或构建无需 SSH、数据库、S3、环境变量或密钥。网络只在显式重新导出时用于读取来源；普通页面资源全部来自静态站点。
