# 学校介绍与美国补充数据

当前版本为 1000 所学校增加来源正文，其中 898 所有中文正文，102 所以英文原文回退并提示。中文在导出时统一为简体。首屏采用已验证的 AI 摘要或来源正文摘要，下方提供详细介绍与展开阅读。AI 摘要仍标为未经人工审核；本次扩写后有 17 所通过生成校验，4 所生成失败使用来源正文回退，不发布未通过校验的输出。

展示数据会清除百科提取残留的空括号及仅含逗号、分号等占位内容的括号，保留有内容的外文名、年份和说明；清理后为空的 infobox 条目不展示。原始快照和旧发布版本仍保留供追溯。

安全明细使用响应式紧凑网格（桌面三列、中屏两列、手机单列），项目与数量成对展示，不跨指标汇总。较长的宿舍记录在有键盘焦点和名称的区域内滚动。

美国及其属地共 350 所：347 所匹配到美国教育部机构数据，343 所有校园安全记录。数据均为已有本地快照，不是实时数据。

## 指标口径

- 收入：接受联邦资助、工作且不再在读的原学生，入学 6 年／10 年后的收入中位数，不是毕业起薪或就业率。
- 债务：毕业生联邦贷款债务中位数。
- 还款：进入还款 3 年后至少偿还 1 美元本金的借款人比例。
- 收入优先取 `MERGED2023_24_PP.csv` 有效值，否则取 `Most-Recent-Cohorts-Institution.csv`。后者未保存各指标独立观测年份，界面明确说明未知，不用导出日期冒充统计年份。不计算 6 年至 10 年的薪资增长率。
- 安全：按校区、来源年份、地点、类别展示。宿舍是校内子集，不跨地点汇总；仇恨犯罪不重复加上偏见类型分项。当地警察另报文件不重复叠加。
- 空白、隐私抑制和无匹配保留为无数据，仅明确的 0 显示为零。
- UNITID 211440 的 2023 年 Fifth Neville Apartments 火灾记录同时有 0 和 1，显示冲突提示及无数据，原值保存在审计报告。

## 再生成与验证

运行 `npm run data:supplements`，通过 SSH 只读读取 192.168.1.229 的现有候选 Parquet、机构映射表及源 CSV/ZIP；不更改源数据库。公开产物为 `public/overviews/<release>/<QID>.json` 和 `public/us-data/<release>/<QID>.json`。美国模块进入视口时只请求当前学校的数据。

发布前在暂存目录验证 ID、发布版本、文件哈希、缺失值与计数，旧文件移入 archives 可恢复。来源文件 SHA256、覆盖率、冲突保存在 `reports/<release>/supplements.json`。运行 `npm test`、`npm run check`、`npm run build` 验证。

官方来源入口：[College Scorecard](https://collegescorecard.ed.gov/data/)；[美国教育部校园安全](https://ope.ed.gov/campussafety/)。详细学校介绍标注百科来源与许可。
