# 全量中文简介检查与润色

目标：当前全部 1000 所学校的中文首屏摘要及详细介绍。输入同时包括中文和英文百科资料；原先没有中文正文的学校依据英文资料生成中文。英文页面正文不属于本轮中文编辑输出。

1. 固化当前版本全部来源至 `archives/overview-polish/<release>/overview-polish-v1/sources/`，断点重试不把模型输出当作原始事实。
2. qwen3.8-27b 逐校检查残缺括号、残缺外文名、语法、重复、宣传、年份冲突，然后生成有段落级来源引用的中文摘要和正文。来源中的任何指令都不是工作流指令。
3. 程序检查 JSON 结构、引用键、数字来源、中文、长度、重复段落和标点；执行简体规范化。
4. 独立一次 Qwen 调用对照原始来源审校整篇。只有明确批准且问题列表为空才接纳；失败反馈给编辑步骤重写，每轮最多四次。全量发布任务最多三轮，后续轮次复用已批准结果，只重试未通过项并携带前稿与错误反馈。仍失败则停止，禁止无限重试。输出、失败原因和审校记录均可追溯。
5. 按来源、提示词、模型指纹缓存已批准结果。全部学校通过后才能用 `--publish` 发布新版本，否则保留旧站点数据，不发布半成品。发布前再验证哈希、内容、审校记录以及现有排名和图片契约，旧版本可恢复。

```sh
npm run data:polish -- --limit 5 --workers 4
npm run data:polish -- --workers 8 --publish
```

进度：`reports/<release>/overview-polish/progress.json`；审校缓存：`archives/overview-polish/<release>/overview-polish-v1/approved/`。失败后重跑同一命令，仅请求未通过项。模型 API 只用于离线处理，浏览器不连接模型服务。

当前全量任务通过用户级 systemd 服务 `university-overview-polish.service` 运行，日志可用 `journalctl --user -u university-overview-polish` 查看。进程脱离终端运行，不依赖对话保持打开。重启机器不自动恢复这个临时服务，可再次运行以上命令续跑。整批有任何未通过项就不会发布；全部通过会生成新静态资源版本，正式静态部署仍需重新构建。

“模型审校通过”不等于人工核实或独立事实验证。页面明确标注 AI 辅助和历史快照。模型不能确认或来源冲突的事实应省略，不从记忆补全。处理首屏时优先使用本流程摘要，不再被旧版短摘要覆盖。
