# 大学图鉴：界面升级（2026-09-28）

## 调研与取舍

本次是案例研究，不是对整个教育行业风格占比的统计。

- [牛津大学](https://www.ox.ac.uk/)：以研究、入学、大学探索等明确栏目组织内容，借鉴其内容导向的分区，而不引入本项目不需要的新闻模块。
- [哈佛大学](https://www.harvard.edu/)：学术、院系与教育项目分层组织，借鉴学校身份与内容阅读优先的思路。
- [QS 排名](https://www.topuniversities.com/qs-world-university-rankings)：排名是探索院校的入口，本项目继续把检索、比较、维度调整作为核心。
- [阿拉巴马大学网页品牌规范](https://brand.ua.edu/web/)：强调品牌一致性与可访问性；正文、辅助文字及焦点态应保持清晰对比。

## 本项目设计方向

采用“教育出版物 + 数据年鉴”，不是复制某所大学的品牌。墨蓝正文、朱红强调、近白底色；衬线刊头与标题，系统无衬线用于表格和操作。不新增远程字体、图片服务或 UI 依赖。

首页使用分栏导读与真实牛津校园摄影，明确标注学校、作者、授权与裁切；照片不代表排名第一或推荐结果。首页年份表示站点版本，不表示全部数据年份。刊头、分隔线与留白建立层级，避免反复堆叠圆角卡片。

榜单筛选显示可见标签；权重面板默认折叠，展开后保留原有交互。名单校徽保持 64/80px，数据与排名计算不变。学校主图继续作为背景；安全报告继续默认折叠，就业数据不随之隐藏。

## 实现位置

- `src/styles/global.css`：色彩、刊头、首页、表格、响应式布局。
- `src/layouts/Layout.astro`：站点导航及公共框架。
- `src/pages/[locale]/index.astro`：双语导读、摄影及收录索引。
- `src/components/Rankings.tsx`：查询界面与权重披露。
- `src/components/SchoolHeader.tsx`：学校页配色和边界。

字体使用本机回退，不保证各操作系统中文衬线字形一致。后续若统一字体，应先确认字体授权并做本地子集化。
