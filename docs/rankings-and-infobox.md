# 排名与学校 infobox

> 本文记录最初 16,132 条原始机构集合的实现情况，已被新版本取代。当前已先进行院校资格与资料质量筛选，再发布前 1,000 所；参见 [当前院校准入规则](admission.md) 和 [本地图片处理](media-acquisition.md)。本文旧记录数、浏览器结果及媒体覆盖不代表当前部署。

本次将六校卡片首页替换为可交互排名模块，并补上六校与其余全部收录记录的基本详情和 infobox。运行地址保持为 `http://192.168.1.220:4322/zh/`。

## 功能

- React 交互岛、TanStack Table 8、Radix Slider / Checkbox、Lucide 图标；Astro 页面与数据全部静态发布。
- 中英文 / QID 搜索，国家 / 地区和大洲筛选，列排序，20 / 50 / 100 条分页。
- 五个维度可独立启用、通过滑块或数字调整；显示归一化百分比。零有效权重显示提示，不生成假排名。
- 调权先重排整个收录集合，再按地区 / 名称筛选；并列按原始加权值保留 12 位小数后的值判断，使用竞争排名（1、1、3）。来源名次保持不变。
- 最多选择四个学校 / 机构，对比同一来源的五维指标，支持移除和清空。
- 20 个学科榜独立 JSON，切换时加载；明确标注为旧版 2025 来源，不套用综合权重。只显示能映射到当前集合的来源前 2000 名，保留旧版原始分数和名次。
- 详情提供建校时间、类型、校训、师生人数、校园环境 / 面积、资金等标准字段，前八项默认展开，其余用原生 details 展开。长文本可单独展开，来源统计年度保留。
- 百科中的 QS / THE / ARWU / U.S. News 排名独立展示并保留原文与年份；缺少年份时不推断为当前年份。

六校仍使用静态 `/zh/university/Q…/` 页面，其他学校由静态 `/zh/university/?id=Q…` 壳按需读取自己的 JSON。由此只生成 17 个页面，避免为 1.6 万条记录同时构建两种语言的空壳页面。一般详情页需要 JavaScript，六校详情及首页默认第一页可直接读取静态 HTML。

## 数据处理

新增 `catalog-20260912T163942Z` 版本，包含 16,132 份双语基本资料与 infobox、完整排名指标文件、20 份学科文件。每份文件有 SHA256，导出先在本地临时目录校验再切换指针。远端只读。

成绩来自 `20251201` 快照：

- 指标或总分不同的 `Q859363`（Sciences Po）暂时排除，完整原始记录保留于审计报告。
- 12 组指标和总分完全一致的重复记录只展示一次，选最小来源名次。默认来源名次因此可能有间隔；不伪装成重新发布的正式名次。
- 12 组折叠和 1 组排除的明细见 `reports/catalog-20260912T163942Z/quality.json`。源 Parquet / DB 不修改。
- 本轮浏览器搜索还发现原成绩集合含 `Tsinghua Holdings` 等关联机构，因此页面使用“学校 / 机构”并明确身份待核验，未自行将整套来源数据认证为正式大学榜单。正式收录过滤仍需独立处理。

Infobox 从候选 Parquet 的 `en_infoboxes` / `zh_infoboxes` 提取，不直接渲染 HTML。处理多张信息卡和中英文别名，过滤图片、地图、拼音等非资料字段，缺失时跨语言回退并标记实际语言。清华英文建校字段的源模板错误值 `29` 已回退到结构化成立年份 `1911`；校园经纬度中存在方向文本错误，未将这些原始坐标文本混入 infobox。

## 验证

- 14 项 JavaScript 测试和 6 项 Python 测试通过，包含全量计分复现、先全局排名后筛选、并列、零权重、源名次不变、infobox 多模板和年度保留。
- 类型检查无错误或警告；样本与全量文件校验通过；生产构建生成 17 页。
- 浏览器实测：国家筛选中国显示 1,096 条，首条北京大学保留来源第 15 名；翻页正常；只启用资金权重后榜首变化为对应最高分机构。
- 四校对比上限与提示正常；全关权重后不显示排名；中英文 / ID 搜索正常。
- 计算机科学榜按需加载一份 JSON，显示 1,973 条；沿用源数据中两校均列第 2 的名次，不擅自修正旧版并列规则。
- 非样本 MIT 详情只请求自己的一份 JSON，显示 17 项 infobox；英文清华详情成立年份显示 1911；原六校校友模块仍保留。
- 390px 移动端详情无横向溢出；排名表在自己的区域内横向滚动。

数据集目前为开发核验版，校友与校徽覆盖仍为六校样本；其他课程、高考、NCES 等模块不属于本次补齐范围。
